A simple redirection manager for WordPress. Manage 301 redirections, keep track of 404 errors, and generally tidy up any loose ends your site may have.

== Description ==

Custom Redirection Manager allows you to easily manage 301 redirections and keep track of 404 errors. This can help reduce errors and improve your site ranking.

Features:
*   Manage 301, 302, 307, and 308 redirections.
*   Log 404 errors to identify broken links.
*   Import redirects from "Simple 301 Redirects" plugin.
*   Lightweight and fast.

== Installation ==

1.  Upload the `custom-redirection-manager` folder to the `/wp-content/plugins/` directory.
2.  Activate the plugin through the 'Plugins' menu in WordPress.
3.  Go to Tools -> Redirection to manage your redirects.
